# Acquisition and research probes

These scripts record exploratory source retrieval and inspection during development. They are not startup commands and some contain one-off database edits or fixed source selections. Retained for research provenance; use the documented `scripts.seed`, `scripts.evaluate`, `scripts.verify_data` and `scripts.export_snapshot` commands for normal reproducibility. Run probes only after reading their code, from the repository root, against a backup when they mutate data.
